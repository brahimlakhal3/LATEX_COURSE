# Dossier des images

Placez ici les images utilisées dans le cours :

- `mon-schema.png`
- `architecture.pdf`
- `capture.jpg`

Puis référencez-les dans un chapitre :

```latex
\begin{figure}[htbp]
\centering
\includegraphics[width=0.75\linewidth]{images/mon-schema.png}
\caption{Ma légende}
\label{fig:mon-schema}
\end{figure}
```

Formats conseillés : **PDF** pour les schémas vectoriels, **PNG** ou **JPG**
pour les captures d'écran.
